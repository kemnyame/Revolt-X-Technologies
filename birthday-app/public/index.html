Secure administrator onboarding

Each new administrator receives a randomly generated temporary password, shown only once. They must set a new password the first time they sign in. Share the temporary password securely with the intended administrator.

STAFF DETAILS

Add staff member

Enter the birthday as DD/MM/YYYY, or DD/MM if the birth year is not available. Staff ID must be unique.

STAFF IMPORT

Import staff birthdays

Upload .xls, .xlsx, .csv or .pdf containing these seven columns: Staff ID, Name, Number, Birthday, Department, Job Title, Email. Birthday format: DD/MM/YYYY. Maximum 2,000 records per import. Re-importing a Staff ID updates its record.

PDF imports must contain selectable text in a table, such as a PDF exported from this application. Scanned or image-only PDFs cannot be imported.
